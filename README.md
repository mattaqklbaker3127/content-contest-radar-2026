## What Is AI Content Contest Radar 2026?

AI Content Contest Radar 2026 is a static HTML application that gathers AI contest listings into a single searchable interface. It covers both domestic and international opportunities, making it easier to review current contests without searching across numerous websites.

The interface is intended for quick evaluation and ongoing personal organization. Results can be narrowed by region, status, deadline, and category, while each listing can include its theme, required submission content, recommendation score, and schedule progress.

## Using the App

Search across contest names, themes, and related listing information with the search box. Filters can be combined to limit the results to the region, status, deadline range, or category that matters to you.

A common way to work with the radar is:

1. Start the app in a browser.
2. Search for a contest or subject of interest.
3. Narrow the results with the available filters.
4. Mark promising contests as favorites.
5. Record comparison notes for later review.
6. Export the selected contest data as CSV or JSON when an offline copy is useful.

## Data and Local Settings

The app manages most user settings through browser localStorage. Favorites and personal notes remain on the device and within the browser profile used to access the app.

To modify listing content or how entries are handled, update the static HTML and associated data files in the repository. Since the project is a static web app, configuration changes are made in the source files rather than in an administration dashboard.
